# 계절 균형 개운 이미지 상품 명세

## 1. 제품 원칙

이 상품은 사주의 계절 균형을 색·빛·자연물·구도로 시각화하는 개인화 이미지다. 이미지를 휴대폰에 저장하거나 배경화면으로 설정하는 행위만으로 실제 운이 좋아진다고 보장하지 않는다. 전통적 상징을 통해 사용자가 자신의 의도와 생활 실천을 자주 떠올리도록 돕는 콘텐츠로 설명한다.

현재 규칙 엔진은 일간 10종과 월령 12종의 선용·후용·보좌 표를 계절 후보 생성에 사용한다. 해당 표는 조후용신을 일간과 출생 월에 따라 정리한 연구 자료에 수록되어 있다.[1] 이후 표면 글자·지장간·월령·뿌리·생조·소모·압박과 합·충·형·해·파 관계를 점검하여 후보를 `우선 보완`, `함께 보완`, `조건부 활용`, `과용 주의`로 재분류한다. 이 결과는 투명한 휴리스틱 기반의 보완 전략이며 최종 용신 확정이나 전문 감정을 대신하지 않는다.

### 1.1 물상 개인화 원칙

개운 이미지는 부족한 오행 하나를 자연물 하나로 치환하지 않는다. 먼저 다음 다섯 층을 분리한 뒤 한 장면에서 상호작용하게 한다.

1. `주인공`: 일주를 사용자가 자신으로 알아볼 수 있는 캐릭터로 표현한다.
2. `계절 환경`: 월주와 월령을 날씨·온도·습도·지면으로 표현한다.
3. `이미 가진 힘`: 원국에 투출하거나 뿌리를 둔 자원을 빛·하늘·큰 지형으로 표현한다.
4. `더 필요한 작용`: 부족한 사물을 추가하지 않고, 데움·식힘·말림·적심처럼 필요한 기능을 장면의 변화로 표현한다.
5. `생조 흐름`: 무엇이 무엇을 거쳐 일주를 돕는지 물길·빛·접촉·행동으로 표현한다.

원국의 물상과 필요한 작용은 설명에서 반드시 구분한다. 예를 들어 `丙寅 / 辛丑 / 甲戌 / 癸酉`에서 큰 태양은 원국에 이미 있는 `병화(태양)`이고, 추가로 필요한 것은 `정화(가까이 머무는 온기)`의 작용이다. 불꽃을 하나 더 그리지 않고 태양의 온기가 땅·물·주인공 가까이에 머무는 모습으로 번역한다.

사용자 설명에서는 전문 용어를 처음 쓸 때 `병화(태양)`, `정화(가까이 머무는 온기)`, `계수(이슬과 맑은 물)`처럼 쉬운 물상을 괄호에 병기한다. 이후 문장에서는 쉬운 표현을 우선한다.

현재 공개 구현 범위에서 위 예시 명식은 사람이 검수한 개인 물상 시안을 제공한다. 그 밖의 명식은 기존 오행 기본형을 보여 주며, 개인 명식 전체를 반영한 실시간 생성 이미지로 표시하지 않는다.

## 2. 상품 구성

### 무료 기본형

- 결과: 약 2K 세로형 JPG 1장
- 스타일: 현대적인 한국 수묵·담채 풍경
- 생성 방식: Gemini 이미지 API로 목·화·토·금·수 기본형 5종을 미리 제작하고 사람이 검수한 뒤 정적 자산으로 배포
- 선택 방식: 월령 후보를 명식 전체에서 재검증한 뒤 `우선 보완` 오행에 맞는 기본형을 표시하고 `함께 보완` 오행을 설명에 결합
- 비용: 사이트 이용 시 외부 이미지 API를 다시 호출하지 않음
- 개인정보: 사전 제작 이미지에는 생년월일·이메일을 전송하거나 기록하지 않음
- 생성 기록: 모델명·프롬프트·usage metadata를 `public/luck-images/*.json`에 보관
- 문구: `상징과 생활 의도를 환기하는 이미지이며 운의 변화나 특정 결과를 보장하지 않습니다.`

무료 기본형은 같은 보완 오행이면 같은 이미지를 사용한다. 개인 명식 전체를 반영한 실시간 생성물로 설명하지 않는다. 개인별 구도와 스타일 변경은 서버가 검증한 판정 JSON만 이미지 API에 전달하는 유료형에서 제공한다.

### 1,900원 건별 상품

기존 사주 상세 문답 3회 상품에 유료 스타일 이미지 1장을 묶는다.

- 상세 문답 3회
- 스타일 1종 선택
- 2K 세로 이미지 1장 생성
- 생성 실패 시 자동 재시도 1회
- 안전·품질 검증 실패는 생성 횟수에서 차감하지 않음
- 결과 링크: 비회원 30일, 회원 계속 보관

선택 스타일은 `맑은 수채화`, `담백한 동양화`, `미니멀 추상`, `자연 사진풍` 네 가지로 시작한다. 작가 이름이나 특정 애니메이션·브랜드 스타일을 선택지로 제공하지 않는다.

### 월 2,900원 구독 — 출시 권장가

- 매 결제 성공 후 해당 월의 2K 세로 이미지 1장 생성
- 사용자가 저장한 기본 스타일을 유지하거나 해당 월 안에 한 번 변경
- 품질 문제에 한해 월 1회 재생성
- 이메일 본문에 이미지 미리보기와 만료 없는 회원 링크 제공
- 비회원 구독은 이메일 일회용 관리 링크로 해지·재결제수단 등록 제공
- 결제 실패 시 이미지를 생성·발송하지 않고 재결제 안내
- 해지 즉시 다음 결제와 다음 달 생성 작업을 중단

토스페이먼츠 자동결제는 별도 계약과 리스크 검토가 필요하고, 빌링키 발급·저장과 주기별 결제 승인 스케줄링을 서비스가 직접 구현해야 한다.[3] 따라서 계약과 테스트가 끝나기 전에는 월 구독 버튼을 공개하지 않는다.

## 3. 이미지 생성 원가 가정

출시 후보 모델은 `gemini-3.1-flash-image`이며 모델 ID는 환경변수로 관리한다. Gemini 공식 가격표에서 이 모델의 2K 이미지 출력은 장당 $0.101로 안내된다.[2]

환율을 1달러=1,500원으로 가정하면:

- 정상 생성 1장: 약 152원
- 정상 생성 1장 + 재생성 1장: 약 303원
- 월 2,900원에서 이미지 생성비가 차지하는 비율: 약 5.2%, 최대 약 10.4%

위 계산에는 입력 토큰, 이메일, 저장소, DB, 서버리스 호출, 결제 수수료, 부가세가 포함되지 않는다. 실제 출시 판단은 100건 이상의 usage metadata와 전체 변동비를 집계한 뒤 다시 한다.

## 4. 판정 JSON

이미지 API에는 생년월일 원문이 아니라 서버가 검증한 판정 JSON만 전달한다.

```json
{
  "engineVersion": "string",
  "rulesetVersion": "string",
  "dayStem": "癸",
  "monthBranch": "巳",
  "seasonalCandidates": [
    { "order": 1, "stem": "辛", "element": "metal", "visible": false, "hidden": false },
    { "order": 2, "stem": "庚", "element": "metal", "visible": false, "hidden": false }
  ],
  "balanceStrategy": {
    "priority": { "element": "metal", "label": "금(金)" },
    "support": { "element": "water", "label": "수(水)" },
    "conditional": [{ "element": "wood", "label": "목(木)" }],
    "caution": [{ "element": "fire", "label": "화(火)" }],
    "model": "whole-chart-balance-v1"
  },
  "annualEvidenceIds": ["string"],
  "monthlyEvidenceIds": ["string"],
  "style": "watercolor",
  "aspectRatio": "9:16",
  "resolution": "2K"
}
```

`monthlyEvidenceIds`는 월운 엔진이 구현되기 전에는 비워 둔다. 지금 단계에서 매달 색만 임의로 바꾸거나 월별 운세가 반영됐다고 표시하지 않는다.

## 5. 이미지 프롬프트 변환 규칙

1. `우선 보완` 기운을 주조색·광원·주요 자연물에 반영한다.
2. `함께 보완` 기운을 보조색·원경·질감에 반영한다.
3. `조건부 활용` 기운은 선행 조건과 부작용을 설명하고 기본 이미지의 주제로 사용하지 않는다.
4. `과용 주의` 기운은 이미지를 위협적으로 제거하는 대신 비중과 강도를 낮춘다.
5. 문자, 부적 기호, 종교 문양, 공포 이미지, 인물 얼굴은 기본 프롬프트에서 제외한다.
6. 특정 작가·브랜드·캐릭터의 화풍을 모방하지 않는다.
7. 결과 이미지의 EXIF와 생성 메타데이터에서 생년월일·이메일·판정 JSON을 제거한다.

## 6. 월별 이미지 판정

월별 이미지는 다음 순서로 계산한다.

1. 원국의 종합 보완 전략을 고정 기준으로 두고 계절 후보표만으로 방향을 뒤집지 않는다.
2. 선택한 연도의 세운 관계와 십이운성 근거를 보조 신호로 사용한다.
3. 절기 기준 월주를 계산한다.
4. 원국 ↔ 세운 ↔ 월운의 합·충·형·해·파와 오행 증감을 계산한다.
5. 원국 후보를 뒤집지 않고 해당 월에 강조하거나 절제할 보조 신호만 추가한다.
6. 사용한 모든 신호에 evidence ID를 부여한다.

월주·월운 엔진과 회귀 테스트가 끝나기 전에는 월 구독을 판매하지 않는다.

## 7. 서버 흐름

### 건별 생성

1. 토스 결제 승인 결과를 서버에서 검증한다.
2. 서버가 규칙 엔진을 다시 실행해 판정 JSON을 만든다.
3. 스타일과 evidence ID를 검증한다.
4. 이미지 생성 API를 호출한다.
5. 이미지 해상도·형식·안전 필터·메타데이터를 검사한다.
6. 암호화 저장소에 업로드하고 주문을 완료한다.
7. 비회원 이메일 링크 또는 회원 보관함에 결과를 연결한다.

### 월 구독

1. 스케줄러가 결제 예정 구독을 조회한다.
2. `subscription_id + billing_period`를 멱등성 키로 결제를 승인한다.
3. 결제 성공 트랜잭션만 `generation_pending`으로 전환한다.
4. 월별 판정 JSON과 이미지를 생성한다.
5. `subscription_id + billing_period + delivery`를 멱등성 키로 이메일을 한 번만 발송한다.
6. 실패는 단계별 재시도하고 중복 결제·중복 이메일을 차단한다.
7. 최종 실패 시 관리자 알림과 사용자 재시도 링크를 보낸다.

## 9. 안전 문구

사용:

> 이 이미지는 사주에서 읽은 계절 균형을 색과 자연 상징으로 표현한 콘텐츠입니다. 배경화면으로 보며 생활 목표와 마음가짐을 떠올리는 데 활용해 보세요. 이미지 저장만으로 운의 변화나 특정 결과를 보장하지 않습니다.

금지:

- 저장하는 순간 운이 열린다.
- 이 이미지를 쓰면 재물운이 반드시 좋아진다.
- 부족한 기운을 완전히 채운다.
- 질병·사고·결혼·임신 결과를 바꾼다.
