# 사이 — 근거를 읽는 사주

생년월일시를 입력하면 사주 네 기둥, 오행 분포, 입문용 해석, 대운과 계산 근거를 보여 주는 반응형 웹사이트입니다.

## 실행

```bash
npm install
npm run dev
```

프로덕션 빌드:

```bash
npm run build
npm run preview
```

## 검증

```bash
npm test
npx playwright install chromium
npm run test:e2e
```

별도 Chromium을 쓸 때는 `PLAYWRIGHT_EXECUTABLE_PATH` 환경 변수를 지정할 수 있습니다.

## 계산 구조

- 절기·연주·월주·음양력 변환·대운: `lunar-javascript` 1.7.7
- 일주: 율리우스일 공식과 `2000-01-01 = 戊午` 기준점으로 직접 계산
- 시주: 일간과 서울 평균태양시(KST 기준 −32분)로 직접 계산
- 한국 표준시 표시: 실행 환경의 IANA `Asia/Seoul` 데이터
- 입력값: 서버 전송·브라우저 저장 없음

## 해석 범위

현재 해석은 천간·지지 여덟 글자의 표면 오행과 일간을 중심으로 한 입문용 규칙입니다. 제공된 참고 이미지에 언급된 원문 98건과 직업 200개 데이터 파일은 전달받지 않았으므로 포함하지 않았고, 사이트에도 그 한계를 표시했습니다.

사주는 자기 이해를 위한 참고 도구이며 건강·재정·법률·진로 결정을 대신하지 않습니다.
